Before WEBBAB can push events to your server, you need to register a webhook subscription. A subscription tells WEBBAB which document type to watch, which action to listen for, and where to deliver the payload. You can manage subscriptions through the WEBBAB dashboard or programmatically via the REST API.

## Prerequisites

- An active WEBBAB account with API access
- An HTTPS endpoint that is publicly reachable (see [Test Webhooks Locally](/guides/webhooks/testing) if you are still in development)
- Your API key and secret (see [Authentication](/guides/authentication))

## Step 1 — Create Your Endpoint

Your webhook endpoint must:

- Accept **HTTP POST** requests
- Parse a JSON body (`Content-Type: application/json`)
- Return **HTTP 200** within the timeout window
- Be accessible over **HTTPS**

Here is a minimal Express.js handler you can deploy:

```javascript
import express from 'express';

const app = express();
app.use(express.json());

app.post('/webhooks/webbab', (req, res) => {
  // Acknowledge immediately — process asynchronously
  res.sendStatus(200);

  const event = req.body;
  console.log('Received event:', event.event, 'for', event.name);
  // TODO: enqueue event for background processing
});

app.listen(3000, () => console.log('Listening on port 3000'));
```

<Tip>
Always send the `200` response before performing any downstream processing. This ensures WEBBAB does not time out and trigger unnecessary retries.
</Tip>

## Step 2 — Register the Webhook via API

Send a `POST` request to `/api/resource/Webhook` with your subscription details. Frappe's resource API creates a new Webhook document on the platform.

<CodeGroup>
```bash cURL
curl -X POST https://your-instance.webbab.se/api/resource/Webhook \
  -H "Authorization: token YOUR_API_KEY:YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "webhook_doctype": "Customer",
    "webhook_docevent": "after_insert",
    "request_url": "https://your-server.example.com/webhooks/webbab",
    "request_method": "POST",
    "request_structure": "Form URL-Encoded",
    "enabled": 1
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://your-instance.webbab.se/api/resource/Webhook',
  {
    method: 'POST',
    headers: {
      'Authorization': 'token YOUR_API_KEY:YOUR_SECRET',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      webhook_doctype: 'Customer',
      webhook_docevent: 'after_insert',
      request_url: 'https://your-server.example.com/webhooks/webbab',
      request_method: 'POST',
      request_structure: 'Form URL-Encoded',
      enabled: 1,
    }),
  }
);

const { data } = await response.json();
console.log('Webhook created:', data.name);
```

```python Python
import requests

response = requests.post(
    'https://your-instance.webbab.se/api/resource/Webhook',
    headers={
        'Authorization': 'token YOUR_API_KEY:YOUR_SECRET',
        'Content-Type': 'application/json',
    },
    json={
        'webhook_doctype': 'Customer',
        'webhook_docevent': 'after_insert',
        'request_url': 'https://your-server.example.com/webhooks/webbab',
        'request_method': 'POST',
        'request_structure': 'Form URL-Encoded',
        'enabled': 1,
    },
)

data = response.json()['data']
print('Webhook created:', data['name'])
```
</CodeGroup>

### Request Body Reference

```json
{
  "webhook_doctype": "Customer",
  "webhook_docevent": "after_insert",
  "request_url": "https://your-server.example.com/webhooks/webbab",
  "request_method": "POST",
  "request_structure": "Form URL-Encoded",
  "enabled": 1,
  "webhook_headers": [
    {
      "key": "X-Custom-Header",
      "value": "my-value"
    }
  ],
  "webhook_data": [
    { "fieldname": "name", "key": "name" },
    { "fieldname": "customer_name", "key": "customer_name" },
    { "fieldname": "territory", "key": "territory" }
  ]
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `webhook_doctype` | string | ✅ | The DocType to watch (e.g. `Customer`, `Sales Order`) |
| `webhook_docevent` | string | ✅ | Lifecycle hook: `after_insert`, `on_update`, `on_submit`, `on_cancel`, `on_trash` |
| `request_url` | string | ✅ | Your HTTPS endpoint URL |
| `request_method` | string | ✅ | Always `POST` |
| `request_structure` | string | ✅ | `Form URL-Encoded` or `JSON` |
| `enabled` | integer | ✅ | `1` to enable, `0` to pause |
| `webhook_headers` | array | — | Additional HTTP headers to include in each delivery |
| `webhook_data` | array | — | Specific fields to include in the payload. Omit to send all fields. |

### Supported Doc Events

| Value | Triggers when… |
|---|---|
| `after_insert` | A new document is saved for the first time |
| `on_update` | An existing document is saved (updated) |
| `on_submit` | A document is submitted (moves to submitted state) |
| `on_cancel` | A submitted document is cancelled |
| `on_trash` | A document is deleted |

## Step 3 — Verify Delivery

After registering your webhook, trigger the event on WEBBAB (e.g. create a new Customer in the dashboard) and check your server logs for the incoming request.

You can also inspect delivery history in the WEBBAB dashboard:

<Steps>
  <Step title="Open Webhooks">
    Navigate to **Settings → Integrations → Webhooks** in the WEBBAB dashboard.
  </Step>
  <Step title="Select your webhook">
    Click the webhook you just created to open its detail view.
  </Step>
  <Step title="View delivery log">
    Scroll to the **Webhook Request Log** section to see each delivery attempt, its HTTP status code, and the response body.
  </Step>
</Steps>

<Tip>
If the delivery log shows a `200` status but your server did not receive the request, check that your firewall or load balancer is not blocking traffic from WEBBAB's IP addresses.
</Tip>

## Step 4 — Update a Webhook

To change the endpoint URL or toggle a webhook on or off, send a `PUT` request to `/api/resource/Webhook/{webhook-name}`.

```bash
curl -X PUT https://your-instance.webbab.se/api/resource/Webhook/HOOK-00001 \
  -H "Authorization: token YOUR_API_KEY:YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "request_url": "https://new-server.example.com/webhooks/webbab",
    "enabled": 1
  }'
```

## Delete a Webhook

To permanently remove a webhook subscription, send a `DELETE` request:

```bash
curl -X DELETE https://your-instance.webbab.se/api/resource/Webhook/HOOK-00001 \
  -H "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

<Warning>
Deleting a webhook immediately stops all future deliveries. In-flight retries may still complete for a brief period after deletion.
</Warning>

## List All Webhooks

Retrieve all registered webhook subscriptions for your instance:

```bash
curl https://your-instance.webbab.se/api/resource/Webhook \
  -H "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```
