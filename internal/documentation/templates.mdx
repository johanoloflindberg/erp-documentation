This page indexes every reusable documentation template available for WEBBAB contributors. Use templates as starting points when creating new documentation — they enforce the correct structure, frontmatter, and component usage from the start. Each template card below describes what the template covers and where to find it.

<Note>
  Templates are living documents. If you find that a template is missing a section your content needs, open a documentation PR to improve it — others will benefit from the improvement.
</Note>

## How to Use a Template

<Steps>
  <Step title="Find the right template">
    Pick the template from the list above that best matches the type of content you are creating. If none fits, use the Doc Standards page to guide your structure.
  </Step>
  <Step title="Copy the raw MDX source">
    Open the template page, view the raw MDX source in the repository, and copy the full file contents.
  </Step>
  <Step title="Create your new file">
    Save the copy to the correct location using the [file structure](/internal/documentation/contributing#file-structure) from the Contributing guide. Use `kebab-case` for the filename.
  </Step>
  <Step title="Replace all placeholders">
    Replace `<Placeholder>` values, fill in TODO markers with real content where known, and delete sections that don't apply to your content.
  </Step>
  <Step title="Register in navigation">
    Add the new page to `docs.json` under the correct navigation group.
  </Step>
  <Step title="Open a PR">
    Follow the [contribution workflow](/internal/documentation/contributing#git-based-documentation-workflow).
  </Step>
</Steps>

## Template Conventions

All templates follow these conventions so pages created from them are consistent:

| Convention | Detail |
|---|---|
| Frontmatter | Every template has a complete `title`, `sidebarTitle`, `description` block |
| Opening paragraph | Plain prose before any heading or component |
| TODO markers | `**TODO**` in bold for every placeholder value |
| Code blocks | All code blocks have language tags |
| Related Pages | `<CardGroup>` at the bottom of every template |
| No raw HTML | Templates never use `<div>`, `<span>`, or Tailwind classes |
