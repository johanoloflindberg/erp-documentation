The Contacts API lets you manage individual people associated with your customers, companies, or other records in WEBBAB. A Contact stores personal details such as name, email, and phone number, and can be linked to one or more parent records through Frappe's Dynamic Link mechanism. All endpoints follow the standard [Frappe REST conventions](/api/frappe/rest-resources).

## List Contacts

Retrieve a paginated list of Contact records. Filter by linked customer, email, or any other field.

```
GET /api/resource/Contact
```

### Query Parameters

<ParamField query="fields" type="string">
  JSON array of field names to return. Example: `["name","first_name","last_name","email_id"]`.
</ParamField>

<ParamField query="filters" type="string">
  JSON array of filter conditions. To find contacts linked to a specific customer, use a filter on the `links` child table — **TODO:** confirm the exact filter syntax for child table fields in your instance.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum number of records to return.
</ParamField>

<ParamField query="start" type="integer" default="0">
  Zero-based offset for pagination.
</ParamField>

<ParamField query="order_by" type="string">
  Sort expression, e.g. `last_name asc`.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Contact?fields=[\"name\",\"first_name\",\"last_name\",\"email_id\"]&limit=10" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/resource/Contact",
    params={
        "fields": '["name","first_name","last_name","email_id"]',
        "limit": 10,
    },
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)
print(response.json())
```
</CodeGroup>

### Example Response

    {

## Retrieve a Contact

Fetch a single Contact record by its unique name.

```
GET /api/resource/Contact/{name}
```

### Path Parameters

<ParamField path="name" type="string" required>
  The unique name of the contact record (e.g. `Jane-Smith-1`).
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Contact/Jane-Smith-1" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/resource/Contact/Jane-Smith-1",
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},

```

</ParamField>

<ParamField body="links" type="array">
  Array of link objects to associate this contact with a Customer or Company. Each object requires `link_doctype` and `link_name`. **TODO:** Confirm structure.

### Example Request

<CodeGroup>
```bash cURL
curl --request POST \
  --url "https://your-instance.webbab.se/api/resource/Contact" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET" \
  --header "Content-Type: application/json" \
  --data '{
    "first_name": "Maria",
    "last_name": "Lindqvist",
    "email_id": "maria.lindqvist@initech.example",
    "phone": "+46705551234",
    "links": [
      {
        "link_doctype": "Customer",
        "link_name": "CUST-00003"
      }
    ]
  }'
```

```python Python
import requests

payload = {
    "first_name": "Maria",
    "last_name": "Lindqvist",
    "email_id": "maria.lindqvist@initech.example",
    "phone": "+46705551234",
    "links": [
        {"link_doctype": "Customer", "link_name": "CUST-00003"}
    ],
}

response = requests.post(
    "https://your-instance.webbab.se/api/resource/Contact",
    json=payload,
    headers={
        "Authorization": "token YOUR_API_KEY:YOUR_SECRET",
        "Content-Type": "application/json",
    },
)
print(response.json())
```

## Update a Contact

Update one or more fields on an existing Contact. Include only the fields you want to change.

```
PUT /api/resource/Contact/{name}
```

### Path Parameters

<ParamField path="name" type="string" required>
  The unique name of the contact record to update.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request PUT \
  --url "https://your-instance.webbab.se/api/resource/Contact/Maria-Lindqvist-1" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET" \
  --header "Content-Type: application/json" \
  --data '{
    "mobile_no": "+46706660000"
  }'
```

```python Python
import requests

response = requests.put(
    "https://your-instance.webbab.se/api/resource/Contact/Maria-Lindqvist-1",
    json={"mobile_no": "+46706660000"},
    headers={
        "Authorization": "token YOUR_API_KEY:YOUR_SECRET",
        "Content-Type": "application/json",
    },
)
print(response.json())
```
</CodeGroup>

### Example Response

```json
{
  "data": {
    "name": "Maria-Lindqvist-1",
    "first_name": "Maria",
    "last_name": "Lindqvist",
    "mobile_no": "+46706660000",
    "modified": "2024-06-15 12:00:00"
  }
}
```
