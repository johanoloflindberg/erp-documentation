The Customers API provides full CRUD access to Customer records in WEBBAB. A Customer represents a business or individual that purchases goods or services through your platform. Customer records link to contacts, addresses, orders, and invoices — making them a central object in the WEBBAB data model. All endpoints follow the standard [Frappe REST conventions](/api/frappe/rest-resources).

## List Customers

Retrieve a paginated list of Customer records. By default, only the `name` field is returned — use the `fields` parameter to request additional data.

```
GET /api/resource/Customer
```

### Query Parameters

<ParamField query="fields" type="string">
  JSON array of field names to include. Example: `["name","customer_name","territory","disabled"]`.
</ParamField>

<ParamField query="filters" type="string">
  JSON array of filter conditions. Example: `[["Customer","territory","=","Sweden"]]`. See [Conventions](/api/conventions) for the full filter syntax.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum number of records to return.
</ParamField>

<ParamField query="start" type="integer" default="0">
  Zero-based offset for pagination.
</ParamField>

<ParamField query="order_by" type="string">
  Sort expression, e.g. `customer_name asc` or `creation desc`.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Customer?fields=[\"name\",\"customer_name\",\"territory\"]&limit=5" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/resource/Customer",
    params={
        "fields": '["name","customer_name","territory"]',
        "limit": 5,
    },
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)
print(response.json())
```
</CodeGroup>

### Example Response

```json
{
  "data": [
    {
      "name": "CUST-00001",
      "customer_name": "Acme Corp",
      "territory": "Sweden"
    },
    {
      "name": "CUST-00002",
      "customer_name": "Globex AB",
      "territory": "Sweden"
    }
  ]
}
```

## Delete a Customer

Permanently delete a Customer record. This action cannot be undone. Frappe may prevent deletion if other records (such as orders or invoices) are linked to this customer.

```
DELETE /api/resource/Customer/{name}
```

### Path Parameters

<ParamField path="name" type="string" required>
  The unique name of the customer record to delete.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request DELETE \
  --url "https://your-instance.webbab.se/api/resource/Customer/CUST-00003" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.delete(
    "https://your-instance.webbab.se/api/resource/Customer/CUST-00003",
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)
print(response.status_code)  # 202 on success
```
</CodeGroup>

### Example Response

```json
{
  "message": "ok"
}
```

<Warning>
  Attempting to delete a customer with linked orders or invoices will return a `409 Conflict` or a `ValidationError`. Archive (disable) the customer instead if you need to preserve linked records.
</Warning>
