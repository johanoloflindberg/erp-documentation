The Projects API gives you access to project records managed within WEBBAB. A Project groups together tasks, milestones, and time logs under a single entity, typically linked to a customer or order. You can use this API to list and monitor projects, read task breakdowns, and check completion status. All endpoints follow the standard [Frappe REST conventions](/api/frappe/rest-resources).

## List Projects

Retrieve a paginated list of Project records.

```
GET /api/resource/Project
```

### Query Parameters

<ParamField query="fields" type="string">
  JSON array of field names. Example: `["name","project_name","status","customer","percent_complete"]`.
</ParamField>

<ParamField query="filters" type="string">
  JSON array of filter conditions. Example: `[["Project","status","=","Open"]]`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum number of records to return.
</ParamField>

<ParamField query="start" type="integer" default="0">
  Zero-based offset for pagination.
</ParamField>

<ParamField query="order_by" type="string">
  Sort expression, e.g. `expected_end_date asc`.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Project?fields=[\"name\",\"project_name\",\"status\",\"percent_complete\"]&filters=[[\"Project\",\"status\",\"=\",\"Open\"]]" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/resource/Project",
    params={
        "fields": '["name","project_name","status","percent_complete"]',
        "filters": '[["Project","status","=","Open"]]',
    },
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)
print(response.json())
```
</CodeGroup>

### Example Response

```json
{
  "data": [
    {
      "name": "PROJ-00001",
      "project_name": "WEBBAB Onboarding — Acme Corp",
      "status": "Open",

      "name": "PROJ-00002",
```

## Retrieve a Project

Fetch a single Project record including its tasks.

```
GET /api/resource/Project/{name}
```

### Path Parameters

<ParamField path="name" type="string" required>
  The unique project name (e.g. `PROJ-00001`).
</ParamField>

<ParamField body="priority" type="string">
