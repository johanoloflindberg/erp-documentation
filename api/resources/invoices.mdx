The Invoices API provides read access to invoice records in WEBBAB. Invoices are typically represented by Frappe's **Sales Invoice** DocType and are the primary billing documents sent to customers. You can use this API to list invoices, retrieve line-item details, check payment status, and obtain PDF download links. All endpoints follow the standard [Frappe REST conventions](/api/frappe/rest-resources).

## List Invoices

Retrieve a paginated list of Sales Invoice records.

```
GET /api/resource/Sales Invoice
```

### Query Parameters

<ParamField query="fields" type="string">
  JSON array of field names. Example: `["name","customer","posting_date","status","grand_total","outstanding_amount"]`.
</ParamField>

<ParamField query="filters" type="string">
  JSON array of filter conditions. Example: `[["Sales Invoice","status","=","Overdue"]]`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum number of records to return.
</ParamField>

<ParamField query="start" type="integer" default="0">
  Zero-based offset for pagination.
</ParamField>

<ParamField query="order_by" type="string">
  Sort expression, e.g. `posting_date desc`.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Sales%20Invoice?fields=[\"name\",\"customer\",\"posting_date\",\"status\",\"grand_total\",\"outstanding_amount\"]&limit=10" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/resource/Sales Invoice",
    params={
        "fields": '["name","customer","posting_date","status","grand_total","outstanding_amount"]',
        "limit": 10,
        "order_by": "posting_date desc",
    },
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)
print(response.json())
```
</CodeGroup>

## Retrieve an Invoice

Fetch a single Sales Invoice record with full line item and tax details.

```
GET /api/resource/Sales Invoice/{name}
```

### Path Parameters

<ParamField path="name" type="string" required>
  The unique invoice name (e.g. `SINV-00010`).
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Sales%20Invoice/SINV-00010" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

## Download Invoice as PDF

Frappe provides a built-in URL for rendering any document as a PDF. This is not a REST resource endpoint but a direct browser-accessible URL.

```
GET /api/method/frappe.utils.print_format.download_pdf
  ?doctype=Sales%20Invoice
  &name={invoice_name}
  &format={print_format}
  &lang=en
```

  **TODO:** Confirm the default print format name for WEBBAB invoices. The `format` parameter must match an existing Print Format in your instance.
</Warning>

### Query Parameters

<ParamField query="doctype" type="string" required>
  Set to `Sales Invoice` (URL-encoded: `Sales%20Invoice`).
</ParamField>

<ParamField query="name" type="string" required>
  The invoice name (e.g. `SINV-00010`).
</ParamField>

<ParamField query="format" type="string">
  The Print Format name to use. **TODO:** Confirm the default WEBBAB invoice print format name.
</ParamField>

<ParamField query="lang" type="string">
  Language code for the PDF (e.g. `en`, `sv`).
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/method/frappe.utils.print_format.download_pdf?doctype=Sales%20Invoice&name=SINV-00010&format=Standard&lang=en" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET" \
  --output invoice-SINV-00010.pdf
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/method/frappe.utils.print_format.download_pdf",
    params={
        "doctype": "Sales Invoice",
        "name": "SINV-00010",
        "format": "Standard",  # TODO: replace with actual format name
        "lang": "en",
    },
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)

with open("invoice-SINV-00010.pdf", "wb") as f:
    f.write(response.content)
```
</CodeGroup>

The response is a binary PDF file (`Content-Type: application/pdf`), not JSON.

## Filter by Payment Status

To find all outstanding (unpaid or overdue) invoices for a specific customer:

```bash
GET /api/resource/Sales Invoice
  ?fields=["name","posting_date","due_date","grand_total","outstanding_amount","status"]
  &filters=[
    ["Sales Invoice","customer","=","CUST-00001"],
    ["Sales Invoice","outstanding_amount",">",0]
  ]
  &order_by=due_date asc
```
