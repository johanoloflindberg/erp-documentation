The Products API provides access to your WEBBAB product catalog. In Frappe, products are typically represented by the **Item** DocType, which stores the product's name, description, pricing details, and availability flags. You can use this API to list available products, retrieve pricing information, and update catalog entries. All endpoints follow the standard [Frappe REST conventions](/api/frappe/rest-resources).

## List Products

Retrieve a paginated list of Item records from the product catalog.

```
GET /api/resource/Item
```

### Query Parameters

<ParamField query="fields" type="string">
  JSON array of field names to return. Example: `["name","item_name","item_group","standard_rate","disabled"]`.
</ParamField>

<ParamField query="filters" type="string">
  JSON array of filter conditions. Example: `[["Item","disabled","=",0],["Item","is_sales_item","=",1]]`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Maximum number of records to return.
</ParamField>

<ParamField query="start" type="integer" default="0">
  Zero-based offset for pagination.
</ParamField>

<ParamField query="order_by" type="string">
  Sort expression, e.g. `item_name asc`.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://your-instance.webbab.se/api/resource/Item?fields=[\"name\",\"item_name\",\"item_group\",\"standard_rate\"]&filters=[[\"Item\",\"disabled\",\"=\",0]]" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET"
```

```python Python
import requests

response = requests.get(
    "https://your-instance.webbab.se/api/resource/Item",
    params={
        "fields": '["name","item_name","item_group","standard_rate"]',
        "filters": '[["Item","disabled","=",0]]',
        "limit": 20,
    },
    headers={"Authorization": "token YOUR_API_KEY:YOUR_SECRET"},
)
print(response.json())
```
</CodeGroup>

### Example Response

```json
{
  "data": [
    {
      "name": "PROD-00001",
      "item_name": "Professional License — Annual",
      "item_group": "Software",
      "standard_rate": 4999.00
    },
    {
      "name": "PROD-00002",
      "item_name": "Support Package — Basic",
      "item_group": "Services",
      "standard_rate": 999.00
    }
  ]
}
```


## Update a Product

Update fields on an existing Item record. To disable a product without deleting it, set `disabled` to `1`.

```
PUT /api/resource/Item/{name}
```

### Path Parameters

<ParamField path="name" type="string" required>
  The item code of the product to update.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl --request PUT \
  --url "https://your-instance.webbab.se/api/resource/Item/PROD-00003" \
  --header "Authorization: token YOUR_API_KEY:YOUR_SECRET" \
  --header "Content-Type: application/json" \
  --data '{
    "standard_rate": 349.00,
    "description": "Updated monthly starter package with extended features."
  }'
```

```python Python
import requests

response = requests.put(
    "https://your-instance.webbab.se/api/resource/Item/PROD-00003",
    json={
        "standard_rate": 349.00,
        "description": "Updated monthly starter package with extended features.",
    },
    headers={
        "Authorization": "token YOUR_API_KEY:YOUR_SECRET",
        "Content-Type": "application/json",
    },
)
print(response.json())
```
</CodeGroup>

### Example Response

```json
{
  "data": {
    "name": "PROD-00003",
    "item_name": "Starter Package — Monthly",
    "standard_rate": 349.00,
    "description": "Updated monthly starter package with extended features.",
    "modified": "2024-06-15 15:00:00"
  }
}
```

<Tip>
  To temporarily remove a product from sales without deleting it, set `disabled` to `1`. Disabled items will not appear in sales order item selectors but remain accessible via the API.
</Tip>
