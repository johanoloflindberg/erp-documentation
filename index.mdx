## Get started in four steps

Follow these steps to go from a fresh account to making live API requests against the Plastkort.nu platform.

<Steps>
  <Step title="Get credentials">
    Log in to your Plastkort.nu account, navigate to **Settings → API Access**, and generate an API key and secret pair. Store your secret somewhere safe — it is shown only once. See [Authentication](/getting-started/authentication) for full details.
  </Step>
  <Step title="Choose an environment">
    Plastkort.nu provides Development, Sandbox, Staging, and Production environments. Start with **Sandbox** so you can experiment freely without affecting real data. Each environment has its own base URL and credential set. See [Environments](/getting-started/environments).
  </Step>
  <Step title="Authenticate">
    Pass your credentials as an `Authorization` header on every request:

    ```http
    Authorization: token YOUR_API_KEY:YOUR_SECRET
    ```

    The platform validates the token and resolves your permissions before processing the request.
  </Step>
  <Step title="Make your first request">
    Call the identity endpoint to confirm everything is wired up correctly:

    ```bash
    curl -X GET "YOUR_BASE_URL/api/method/frappe.auth.get_logged_user" \
      -H "Authorization: token YOUR_API_KEY:YOUR_SECRET"
    ```

    A `200 OK` response with your username confirms your integration is live.
  </Step>
</Steps>
