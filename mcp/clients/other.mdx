The WEBBAB MCP server implements the open Model Context Protocol specification, so any MCP-compatible client can connect to it. This page provides a generic configuration reference and guidance for clients not covered by a dedicated guide — including ChatGPT (with MCP support), custom agent frameworks, and direct MCP SDK integrations.

<Info>
  For step-by-step guides for specific clients, see [Claude](/mcp/clients/claude), [Cursor](/mcp/clients/cursor), and [VS Code](/mcp/clients/vscode).
</Info>

## Generic MCP Client Configuration

Most MCP clients follow a common configuration pattern. You need three pieces of information:

| Field | Value |
|-------|-------|
| Server URL | `https://your-instance.webbab.se/mcp` |
| Authentication | Your WEBBAB API key |
| Server name | Any identifier, e.g. `webbab` |

The canonical configuration object looks like this:

```json
{
  "mcpServers": {
    "webbab": {
      "url": "https://your-instance.webbab.se/mcp",
      "auth": {
        "type": "api_key",
        "api_key": "YOUR_API_KEY"
      }
    }
  }
}
```

## Custom Agent Frameworks

If you are building a custom AI agent using a framework such as LangChain, LlamaIndex, AutoGen, CrewAI, or a direct LLM API integration, you can connect it to the WEBBAB MCP server using the MCP SDK.

### MCP SDK — TypeScript / JavaScript

<Info>
  **TODO:** Exact SDK package names, import paths, and API surface are pending verification against the official MCP SDK releases. The examples below reflect the expected patterns. Replace `YOUR_TOOL_NAME` with an actual tool name discovered via `client.listTools()` — confirmed tool names are pending documentation from the WEBBAB platform team.
</Info>

```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const transport = new StreamableHTTPClientTransport(
  new URL("https://your-instance.webbab.se/mcp"),
  {
    requestInit: {
      headers: {
        Authorization: `Bearer ${process.env.WEBBAB_API_KEY}`,
      },
    },
  }
);

const client = new Client(
  { name: "my-webbab-agent", version: "1.0.0" },
  { capabilities: {} }
);

await client.connect(transport);

// List available tools — use the returned names for subsequent calls
const { tools } = await client.listTools();
console.log("Available tools:", tools.map((t) => t.name));

// Call a read tool (replace "YOUR_TOOL_NAME" with a name from listTools())
const result = await client.callTool({
  name: "YOUR_TOOL_NAME",
  arguments: { query: "Eriksson" },
});

console.log("Result:", result.content);
```

### MCP SDK — Python

<Info>
  **TODO:** Python MCP SDK package name and API surface are pending verification. The example below reflects the expected pattern based on the MCP specification. Replace `YOUR_TOOL_NAME` with an actual tool name discovered via `session.list_tools()`.
</Info>

```python
import os
import asyncio
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

async def main():
    server_url = "https://your-instance.webbab.se/mcp"
    api_key = os.environ["WEBBAB_API_KEY"]

    async with streamablehttp_client(
        server_url,
        headers={"Authorization": f"Bearer {api_key}"}
    ) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # List available tools — use the returned names for subsequent calls
            tools = await session.list_tools()
            print("Available tools:", [t.name for t in tools.tools])

            # Call a read tool (replace "YOUR_TOOL_NAME" with a name from list_tools())
            result = await session.call_tool(
                "YOUR_TOOL_NAME",
                arguments={"query": "Eriksson"}
            )
            print("Result:", result.content)

asyncio.run(main())
```

## Connection Parameters Reference

Use these values when configuring any MCP-compatible client:

| Parameter | Value |
|-----------|-------|
| Protocol | MCP over HTTP (Streamable HTTP transport) |
| Server URL | `https://your-instance.webbab.se/mcp` |
| Authentication | API key (Bearer token or header — TODO: confirm exact method) |
| TLS | Required — all connections must use HTTPS |

## Security Considerations for Custom Agents

When building a custom agent that connects to the WEBBAB MCP server, apply these practices:

- Always load the API key from an environment variable or secrets manager — never hard-code it.
- Create a dedicated WEBBAB service account for the agent with only the roles it needs.
- Log all tool invocations in your agent's own audit trail.
- Implement a human-in-the-loop confirmation step before your agent executes write tools.
- Handle `401` and `403` responses gracefully — revoke and rotate keys if you receive unexpected authentication errors.

See [Security](/mcp/security) for the full security model.
